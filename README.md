# El huésped de la habitación cerrada

Página estática de lectura y comprensión para YV Español.

## Publicar en GitHub Pages

1. Extraiga el archivo ZIP.
2. Envíe todo el contenido de la carpeta al repositorio.
3. En **Settings → Pages**, seleccione la rama principal y la carpeta raiz.

La lectura usa a API `speechSynthesis` do navegador e prioriza vozes `es-ES`. A voz disponível pode variar conforme o aparelho e o navegador.
